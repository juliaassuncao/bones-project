# 09 — Créditos, origem e cuidados editoriais

## Créditos

- **Obra literária:** *Bones*, por **marydebones**.
- **Referência canônica:** `https://archiveofourown.org/works/84490006`.
- **Playlist indicada pela autora:** `https://open.spotify.com/playlist/5cqfMuLJNFAFCvoouDyklL`.
- **Arte central:** capa da playlist, enviada para desenvolvimento do projeto.
- **Fandom indicado na obra:** Três Graças (TV).

## Nota da autora que deve ser respeitada

O PDF registra que Bones surgiu originalmente como história Camren em coautoria; a releitura atual é desenvolvida pela Mary, reconhecendo o trabalho e os direitos da coautora na versão original. O site reproduz o aviso correspondente na página `/sobre`.

## Situação de permissões

O fornecimento do PDF neste chat autoriza seu uso técnico para esta tarefa de desenvolvimento, **mas não estabelece por si só autorização de distribuição pública**. Antes de publicar os 28 capítulos, a arte da playlist e as sete imagens extraídas, alinhar o uso com a autora e demais titulares de direitos relevantes.

## Diretrizes

- Não atribuir textos-conceito produzidos para a interface à autora da fic.
- Não alterar nomes, acontecimentos, cenas ou falas no processo de design.
- Não usar arquivos de áudio de terceiros sem direitos de reprodução; abrir o Spotify oficial.
- Não realizar mudanças que escondam alertas de violência, conteúdo explícito, luto ou suicídio.
- Não confundir a interface independente com a plataforma oficial AO3.
- Incluir link permanente para a obra e espaço visível para a autora.

## Atribuição de dados

Os dados do projeto são derivados do PDF disponibilizado para este desenvolvimento. A lista musical em `src/data/soundtrack.ts` é uma curadoria **não exaustiva**, conferida em notas e trechos relevantes do documento.
